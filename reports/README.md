# Verification evidence

- `tests/index.html`: archived complete Chromium desktop/mobile suite, including visual comparisons.
- `tests/production/index.html`: optimized-build worker, persistence and observer lifecycle checks.
- `tests/public/index.html`: anonymous HTTPS desktop/mobile validation of the published game, including exact build bytes and real-time pending recovery.
- `deployment/public-menu-desktop.png` and `public-menu-mobile.png`: screenshots captured from the public URL.
- `PROFILING.md`: interpreted frame-rate and memory results, reference environment and limitations.
- `profiling/latest.json`: raw frame intervals, entity samples, environment, heap/DOM counters and build hash.
- `profiling/menu-before.heapsnapshot.gz` and `profiling/menu-after-five.heapsnapshot.gz`: compressed Chrome heap snapshots around five repeated cycles. Decompress with a gzip utility and load them in Chrome DevTools Memory for comparison.
- `profiling/result.png`: end of the real-time three-minute workload.
- `profiling/heap-comparison.json` and `heap-object-signatures.json`: reproducible heap investigation, generated by `pnpm run profile:heaps`.
- `profiling/renderer-comparison.json`: 45-second measurements in software Chromium and GPU-accelerated Chrome, with actual renderer identities.
- `profiling/chrome.cpuprofile.gz` and `headless-shell.cpuprofile.gz`: compressed DevTools CPU sampling profiles for the comparison. Decompress and import in DevTools Performance.
- `failures/public-system-ca/index.html`: the initial public run's HTTP certificate-trust failures, including retained traces. Node 24's system trust store resolves this environment issue with TLS verification enabled; final successful public checks are reported separately above.

Reproduce with the commands in README. Run the full browser suite, production suite and `pnpm run reports:archive` sequentially. Playwright retains traces/screenshots on failure in `test-results`; the archived HTML includes failed-run attachments when present. A successful run has no failure trace. Baseline PNGs remain in the test source tree, not in these generated reports.

Public validation is recorded separately from local production checks. Performance evidence is specific to the recorded renderer, viewport and workload.

The complete archived suites describe the measured release with entry SHA-256 `02748a6e...`. The final collector-only adjustment subsequently passed the two focused production observer cases and a strict production build; the full suites were not repeated. README and PROFILING.md distinguish the current release from the earlier evidence. No three-minute hardware or visible-window result is claimed.
